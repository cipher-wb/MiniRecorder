# 轻录 — Claude Code 风格 · 开发交接

终端控制面板皮肤的高保真原型。`轻录 - Claude Code 风格.html` 在浏览器直接打开即可
预览（浅色 / 深色并排，全部可交互）。下方是落地到正式软件（Qt/QSS 或前端）所需的设计 token。

## 文件
- `轻录 - Claude Code 风格.html` — 页面外壳 + 全部 CSS（设计系统在 `<style>` 里）
- `app.jsx` — 录制面板组件 + 交互逻辑（React）
- `tweaks-panel.jsx` — 调参面板（仅原型用，正式软件不需要）

> 原型用 CDN 加载 React / Babel / 字体，需联网。正式软件不必带这套，照下面 token 重画即可。

## 字体
- 全部等宽：**IBM Plex Mono**（备选 JetBrains Mono / Space Mono / DM Mono）
- 中文回退：Noto Sans SC / 系统等宽
- 关闭连字：`font-feature-settings: "liga" 0, "calt" 0;`（保证 `--flag` 显示为双连字符）

## 设计要点（迁到正式 UI 时保留）
1. **CLI flag 配置行**：`--mode` / `--quality` / `--source` 用 accent 色、字距 `.1em`，右侧是下拉框。
2. **提示符状态行**：`$ rec --status ● idle`，待机时尾随闪烁光标 `▋`；录制时状态点用 accent 脉冲动画，右侧等宽计时器 `00:00:00`。
3. **录制按钮**：待机=实心 accent + 圆点图标 + 右侧键帽 `F9`；录制中=描边 inset 风格（冷静、与待机区分）+ 方块图标 + 文案「停止录制」。
4. **键帽 kbd**：小号等宽，加边框圆角，提示 F9 / F10。
5. **图标用 CSS/SVG 几何形**（圆点=录制、方块=停止、双竖条=暂停、三角=继续），不用 emoji。
6. **ASCII 装饰线**可开关：config 区上下各一条 `────` / `· · ·` 虚线。
7. 圆角：窗口 12px，输入/下拉 7px，按钮 9px。

## 功能对应（与原 PySide6 版本一致）
模式（全屏/窗口/自定义区域）· 质量预设 · 屏幕/窗口来源选择 · 开始/停止 · 暂停/继续(F10) ·
打开输出目录 · 设置 · 置顶 · 托盘最小化。视觉是新皮肤，行为不变。
